# 完整移除项目功能设计

## 背景

线上站点仍显示“项目”导航。当前源码已经把该导航项注释，但项目功能仍完整存在：Astro 内容集合仍加载 `content/projects`，`/projects` 分页路由仍会生成，标签聚合仍读取项目数据，项目专属组件、工具函数和主题配置也仍保留。

导航与当前源码不一致，说明线上部署产物并非由当前提交生成，或仍命中旧缓存。仅重新部署只能隐藏导航，不能满足“导航和页面完全删干净”的要求。

## 目标

- 导航配置中不再存在“项目”入口或注释残留。
- 构建不再生成 `/projects` 及其分页页面。
- 删除项目内容集合、示例内容、组件、工具函数和专属主题配置。
- 标签列表、标签计数和标签详情仅基于文章。
- 保留文章正文中作为普通中文名词出现的“项目”，例如技术文章对当前代码工程的描述。

## 方案

采用干净切除，不设置功能开关，不保留兼容别名或隐藏代码。

### 导航与配置

- 删除 `src/theme.config.ts` 中被注释的项目导航项。
- 删除 `projectsPerPage` 与 `projectsView` 配置。
- 从 `ThemeConfig`、默认配置及相关类型中删除对应字段。

### 路由与界面

- 删除 `src/pages/projects` 下的项目分页路由。
- 删除 `src/components/projects` 下的项目列表、网格和列表项组件。
- `/projects` 不再存在于静态构建产物中，由托管平台按普通不存在路径处理。

### 内容与数据

- 从 `src/content.config.ts` 删除 `projects` 集合及其 schema。
- 删除 `content/projects` 下的项目 Markdown 内容。
- 删除 `src/util/projects.ts`。

### 标签功能

- `generateTags` 只从文章集合生成标签。
- `getTagUsage` 只统计文章数量。
- 标签详情页删除项目查询、项目标题与项目列表，只显示匹配文章。

## 验证

1. 先增加针对标签聚合的回归测试，证明现有实现仍依赖项目集合；该测试在实现前必须按预期失败。
2. 完成删除后运行定向测试，确认标签只统计文章。
3. 运行 Astro 类型检查和生产构建。
4. 检查 `dist`，确认没有生成 `projects` 目录或项目页面链接。
5. 启动本地生产预览并通过浏览器确认：桌面和移动导航均无“项目”，标签详情无 Projects 区块，访问 `/projects/` 返回不存在页面。

## 部署要求

代码删除不能直接解释或刷新现有线上缓存。合并后必须让线上平台从包含本次修改的提交重新构建，并清除旧静态产物或 CDN 缓存；否则旧导航和旧 `/projects` HTML 仍可能继续被访问。

## 非目标

- 不修改文章正文、时间轴或说明文档中作为普通语义出现的“项目”一词。
- 不新增 `/projects` 重定向或兼容页，因为目标是完全删除该页面。
- 不调整其它导航、页面样式或动画。
