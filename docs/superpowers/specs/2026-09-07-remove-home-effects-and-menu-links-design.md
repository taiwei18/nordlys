# 删除首页特效与示例导航设计

## 目标

降低首页运行时开销，并从“其它页面”菜单移除主题自带的作者、标签示例入口。

## 范围

### 首页

- 从 `src/layouts/LandingLayout.astro` 移除 `FloatingLines` 导入与渲染层。
- 删除失去调用方的 `src/components/FloatingLines.tsx`。
- 从 `package.json` 与 `pnpm-lock.yaml` 移除仅供该特效使用的 `three` 依赖。
- 保留首页标题由 `background: true` 控制的静态柔光，不改变首页文字、布局、页脚或主题模式。

### 其它页面菜单

- 从 `src/theme.config.ts` 的“其它页面”子菜单删除“作者：FjellOverflow”。
- 从同一子菜单删除“标签：documentation”。
- 保留“首页”和“404 页面”入口。

## 明确保留

- 顶部“标签”主导航。
- `/tags/`、`/tags/[tag]/` 与 `/authors/[author]/` 路由。
- 文章和项目中的标签展示。
- 文章作者展示、内容集合字段、结构化数据与 SEO 元数据。
- 其他动效组件及其依赖。

## 实现原则

采用干净切换，不保留未使用的特效组件或依赖。修改限定在特效接入点、特效组件、依赖声明、锁文件和导航配置，不做无关重构。

## 验证

1. 执行生产构建，确认 Astro 编译、静态路由生成与 Pagefind 索引成功。
2. 启动站点并在浏览器访问首页，确认动态线条背景不再渲染，首页其余内容正常。
3. 展开“其它页面”菜单，确认作者和标签示例入口消失，“首页”和“404 页面”仍存在。
4. 确认顶部“标签”主导航仍存在。
